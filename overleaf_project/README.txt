HOW TO USE IN OVERLEAF:
------------------------------------------------------------------------
METHOD 1 (Recommended - 1-Click Upload):
1. Go to Overleaf (https://www.overleaf.com)
2. Click "New Project" -> "Upload Project"
3. Select "ConstrumindNet_Overleaf_Package.zip"
4. Overleaf will unpack everything and compile "main.tex" automatically!

METHOD 2 (Copy-Paste into Blank Project):
1. In Overleaf, create a "Blank Project" (e.g., named "ConstrumindNet_Paper").
2. Open "main.tex" in Overleaf and paste the contents of "main.tex" from this folder.
3. Click "New File" -> Name it "references.bib" -> Paste the contents of "references.bib".
4. Click "Recompile". Done!

FILES INCLUDED:
------------------------------------------------------------------------
- main.tex:
    Universal Overleaf-ready LaTeX document formatted with standard packages
    (amsmath, geometry, booktabs, authblk, algorithm, hyperref).
    Compiles cleanly with pdfLaTeX on Overleaf without any missing class files!

- sn-article.tex:
    Official Springer Nature `sn-jnl.cls` template version ready for formal
    submission to Discover Computing / Springer journals.

- references.bib:
    Complete BibTeX bibliography containing all 67 academic citations.

- RESEARCH_PAPER_EQUIPMENT_ALLOCATION.md:
    The full markdown version with embedded ASCII diagrams and tables.
